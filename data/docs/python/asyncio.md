# asyncio: tareas y event loop

La biblioteca asyncio permite concurrencia cooperativa en Python mediante corutinas, tareas y un event loop. Una función declarada con async def devuelve una corutina al llamarse. Se ejecuta al esperarla con await o al programarla como Task. asyncio.create_task(coro) programa una corutina para ejecutarse concurrentemente con otras tareas. asyncio.run(main()) crea y cierra el event loop para un programa de entrada. await asyncio.gather(*tasks) espera varias tareas y devuelve sus resultados en el orden original. asyncio.TaskGroup ofrece concurrencia estructurada: al salir del bloque espera todas las tareas y propaga errores del grupo. Para trabajo bloqueante de CPU o bibliotecas sin soporte asíncrono se puede usar asyncio.to_thread, evitando bloquear el event loop.
